TXN-001 LIVE MOBILE IN PROGRESS sha512:9f2c…a41e

PayXpress fintech · bill payments & wallets · Nigeria

A bill-payment and wallet platform for the Nigerian market. Next.js on Vercel in front, Spring Boot on Railway behind, real money in the middle — so the interesting problems are all about trust, integrity and concurrency.

  • CR SECURITY

    Signed biller requests. Every call to the billers API carries an HMAC-SHA512 signature — a tampered payload never survives the gateway.

  • CR INTEGRITY

    Dual-confirmation payments. Paystack webhooks are verified twice — signature check plus a server-side re-query — before a single kobo touches a wallet.

  • DR RACE COND.

    Race-proof wallet. Balance mutations run under pessimistic database locks, so two simultaneous debits can't double-spend the same balance.

  • CR AUTH

    Auth migration in production. Moved the platform off phone/BVN verification to email OTP without breaking existing users.

  • DR IN FLIGHT

    Mobile client in React Native, under active development.
